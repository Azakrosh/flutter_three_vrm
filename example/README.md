# flutter_three_vrm example

Production API demonstration for Android and Windows.

The responsive command gallery is displayed on the right on desktop and at the
bottom on mobile. Its tabs demonstrate model lifecycle, VRMA/Pose transitions,
facial expressions and moods, amplitude/viseme speech input, scene controls,
camera state, graphics profiles, and runtime diagnostics using only the public
package API.

The bundled `sample.vrm` and `sample.vrma` are pinned official test assets.
Their source, checksums, and redistribution terms are documented in
[`THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md). Do not add avatar or
animation files without first verifying their redistribution permissions.
