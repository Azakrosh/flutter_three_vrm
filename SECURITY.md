# Политика безопасности

## Поддерживаемые версии

До первого стабильного релиза исправления безопасности выпускаются только для
последней версии ветки `0.2.0-dev.x`. Старые prerelease-версии и `0.1.x` не
поддерживаются.

## Сообщение об уязвимости

Не публикуйте сведения об уязвимости в issue, discussion или pull request.
Используйте приватный отчёт GitHub: вкладка **Security** →
**Report a vulnerability**. Владелец репозитория должен включить Private
vulnerability reporting до объявления репозитория публичным.

Приложите:

- затронутую версию или commit;
- Android/Windows, версию ОС, Flutter и WebView;
- минимальные шаги воспроизведения или proof of concept;
- ожидаемое влияние;
- известные способы временно снизить риск.

Подтверждение отчёта и срок исправления зависят от воспроизводимости и тяжести.
Публичное раскрытие согласуется после выпуска исправления.

## Граница доверия

Пакет исполняет локальный web-runtime внутри WebView. Сетевую авторизацию и
загрузку защищённых моделей должно выполнять Flutter-приложение. Не передавайте
access/refresh tokens, cookie, API keys или другие долгоживущие секреты в
JavaScript-контекст. Загружайте проверенные bytes или локальный файл через
высокоуровневый API пакета.
